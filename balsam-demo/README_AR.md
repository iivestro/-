# بلسم — بيئة تدريب منفصلة

هذه النسخة داخل `/balsam-demo/` تستخدم مشروع Supabase المخصص للتدريب، وتحتوي صفحات الواجهات ودوالها في المسارات القياسية لـ Supabase CLI. كل صفحة تعرض تنبيهاً بأن البيئة تدريبية. لا تدخل أسماء أو أرقاماً أو تقارير طبية لأشخاص حقيقيين.

## تسجيل المراجع في بيئة التدريب

- تستخدم بوابة المراجع دالة `patient-username-auth`؛ الدخول بالاسم الكامل وكلمة المرور.
- كلمة المرور لا تقل عن 10 أحرف. الاسم الكامل والعمر والمحافظة مطلوبة عند التسجيل.
- بيانات الاعتماد الداخلية لا تُعرض للمستخدم، ومفتاح الخادم لا يوجد في صفحات HTML.
- يلزم وجود حساب مدير وأطباء ومراكز تدريبية لإكمال كل المسارات؛ لا تنشئ حسابات أشخاص حقيقيين.

## فتح التطبيق

الرابط بعد نشر المجلد: `https://iivestro.github.io/-/balsam-demo/`.
يمكن تثبيته كتطبيق ويب على الهاتف من المتصفح. ملف `sw.js` يخزن واجهة التطبيق المحلية فقط ولا يخزن طلبات Supabase أو بيانات المستخدمين. هذه نسخة PWA وليست APK أو IPA للمتاجر.

## نشر التدريب لاحقاً

استخدم إعدادات `supabase/config.toml` داخل هذا المجلد، وانشر الدوال لهذا المشروع فقط. الترحيلان `20261128000000_enable_visit_services_and_schedule_reminders.sql` و`20261128000010_patient_medical_records.sql` يجهزان الخدمات وسجل التقارير الطبية في التدريب؛ الأول يفعّل الدعم والدور والبحث القريب والتذكير ويضبط مهمة التذكير كل 15 دقيقة بعد وجود جداول ووظائف الأساس.

هذه الحزمة لا تنشر أو تطبق أي تغييرات تلقائياً على الإنتاج أو التدريب.
