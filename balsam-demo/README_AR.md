# بلسم | النسخة التجريبية

هذه نسخة ويب قابلة للتثبيت كتطبيق على Android وiPhone، وتضم بوابات المراجع والطبيب والمركز والإدارة والمندوبين والطوارئ والخدمات المنزلية كما في الموقع الحالي.

## السلامة
- جميع صفحات الواجهة تستخدم مشروع Supabase التجريبي PATIENT-STAGING، ولا تتصل بمشروع الإنتاج.
- يظهر تنبيه «بيانات تدريب فقط» على كل بوابة.
- لا تدخل بيانات مرضى حقيقية أو مستندات طبية حقيقية.
- حساب المراجع يستخدم اسم دخول مميزاً وكلمة مرور، من دون طلب هاتف أو بريد. الاسم الكامل للعرض، والعمر والمحافظة لملف المراجع.
- استعادة كلمة مرور المراجع يدوية عبر الإدارة لأن الحساب لا يحتوي بريداً أو هاتفاً.
- حساب المراجع يُفعّل مباشرة. تبقى موافقات الإدارة مطلوبة لباقي أنواع الحسابات.
- لا تنشئ حسابات لأشخاص حقيقيين أو ترفع مستندات طبية حقيقية.
- أُضيفت دالة التسجيل في backend/patient-username-auth/index.ts وجداولها في backend/patient-username-auth/migration.sql. الدالة مخصصة لـ staging وتستخدم مفتاح Supabase السري داخل Edge Function فقط.
- مشروع staging لا يحتوي حسابات تدريب أو بيانات أطباء/مراكز، وبعض دوال الإدارة الأخرى غير منشورة فيه؛ لذلك بعض المسارات لا تعمل حتى تُجهز البيانات والدوال الناقصة.

## تجربة على الهاتف
1. واجهة بلسم منشورة في https://iivestro.github.io/-/balsam-demo/.
2. افتح الرابط على Android بواسطة Chrome واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
3. على iPhone افتح الرابط في Safari واختر مشاركة ثم «إضافة إلى الشاشة الرئيسية».
4. سجّل المراجعين عبر Edge Function patient-username-auth في مشروع staging.

هذه نسخة PWA؛ ليست APK/IPA جاهزة للمتجر. يمكن إضافة غلاف Capacitor أو بناء أصلي بعد تثبيت الاستضافة النهائية ومعالجة تسجيل الدخول العميق والإشعارات.
