# PATIENT mobile preview

Expo SDK 57 / React Native 0.86 / TypeScript. Initial local Arabic portal navigation only; no backend connection or credentials. For an iPhone with compatible Expo Go, install Node.js 22 (22.13 or later), download the branch, open v2/mobile, run `npm install`, `npx expo install --check`, `npx expo login`, then `npx expo start --tunnel`. Sign in to the same Expo account on the phone and scan the QR code. Check SDK compatibility first; if mismatched use the corresponding development build instead. Do not enter real patient data. Package identifiers, signing, privacy disclosures, secure device sessions and full feature parity remain release gates. No paid provisioning or store submission.
