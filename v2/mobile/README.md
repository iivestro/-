# PATIENT mobile portal preview

Expo React Native phone preview embeds the existing HTTPS web portals from https://iivestro.github.io/-/ using react-native-webview. It does not replicate or copy database records and does not use the v2 staging API. The underlying original portal's own authentication, authorization and backend remain in effect. Use authorized synthetic accounts only; never enter actual medical/patient data in Expo Go. Actions in the original portal can affect its existing database. Emergency chat deliberately not included. The preview uses temporary WebView sessions, disables file access, mixed content and geolocation, and restricts top-level navigation to known portal paths. External HTTPS links require confirmation. Test maps, uploads, location-based home services, logout and cross-portal flows separately; they may need native implementation or browser fallback.

For an already working local copy: stop Metro, install the SDK-compatible WebView via `npx expo install react-native-webview`, replace App.tsx with the current branch file, and restart Metro using the previously working connection mode. For a fresh checkout verify dependencies with `npx expo install --check`. No store submission or paid provisioning. Native feature migration remains a separate effort.
